🎤 Tavern Multi-TTS — 酒馆多引擎语音脚本
给你的角色加上声音吧！这是一个 SillyTavern 酒馆助手脚本，让 AI 角色的台词可以直接朗读出来。支持多个 TTS 引擎，支持为不同角色绑定不同的声音。

✨ 它能做什么？
简单来说：AI 回复里的角色台词 → 自动变成可点击播放的语音片段。

你可以在聊天界面直接点击台词听到角色说话，还能一键下载音频文件。

🔧 支持的 TTS 引擎
引擎	说明
MiniMax	海外可用的云端 TTS，需要 API Key + Group ID，支持丰富的系统音色和自定义克隆音色
Local-GSVI	本地部署的 GPT-SoVITS 推理服务，适合有显卡的玩家，完全免费无限制
两个引擎可以随时切换，配置互不干扰。

🎭 核心功能
1. 角色语音映射
每个角色可以绑定专属的音色。当 AI 输出 <say char="爱丽丝">你好呀</say> 时，会自动使用你为"爱丽丝"配置的专属声音来合成语音。

2. 提示词自动注入
脚本会自动向 AI 注入提示词，引导模型在角色台词上自动包裹 <say char="角色名"> 标签，不需要你手写正则或修改角色卡。注入深度、角色名、模板内容都可以自定义。

3. 映射存档系统
角色映射可以保存为存档（比如"A卡"、"B卡"），切换角色卡时一键读取，不用每次重新配置。MiniMax 和 GSVI 各有独立的存档系统。

4. 语音预取策略
仅点击时生成：省资源，点哪句才合成哪句
自动预取前 N 句：折中方案，自动提前合成前几句
自动预取全部：回复一出来就全部合成好（MiniMax 推荐）
5. 音频缓存
已合成的语音会缓存在浏览器 IndexedDB 中（上限 100 条 / 50MB），重复播放不会重复消耗额度或请求。支持手动清空。

6. 音色列表拉取（MiniMax）
一键拉取你账号下所有可用音色（包括系统音色、克隆音色、生成音色），支持按语言/性别/来源筛选，选中后可直接绑定到角色。

7. 模型与情绪映射（GSVI）
自动从你的 GSVI 服务拉取所有可用模型版本，每个角色可以单独配置模型、语种、情绪参数。

🚀 快速上手
MiniMax 引擎
在 MiniMax 开放平台 获取 API Key 和 Group ID
安装脚本后在扩展设置中找到 Tavern Multi-TTS 面板
填入 API Key 和 Group ID
点击「拉取音色列表」选择一个默认音色
新增角色映射，为你的角色们绑定专属声音
开始聊天，台词会自动变成可点击的语音片段 🎧

Local-GSVI 引擎
本地部署好 GPT-SoVITS 推理服务
TTS 引擎切换到 Local-GSVI
填入服务地址（如 http://localhost:9880）
点击「拉取模型与情绪映射」
选择默认模型、语种、情绪
为角色绑定不同的模型版本即可

⚙️ 高级设置一览
语速 / 音量：滑块调节，实时生效
鉴权 Token：GSVI 服务如果有鉴权可以填 Bearer Token
文本语言 / 切分方式 / Batch Size：GSVI 专属的精细调参
注入深度 / 角色 / 模板：完全自定义提示词注入行为
测试语音：支持日/中/英三种语言的测试文本，配好就能试听

💡 小贴士
配置会自动保存，不需要手动点保存按钮
如果 AI 没有正确输出 <say> 标签，检查一下「提示词注入」是否开启，以及注入模板是否包含 ${mapped_characters}
MiniMax 每次合成会消耗 API 额度，建议先用「仅点击时生成」模式测试
GSVI 建议使用「仅点击时生成」或「自动预取前 N 句」，避免一次性大量请求拖慢本地服务
角色映射支持检测重复角色名，重复时以最后一条为准

📦 安装方式
作为酒馆助手脚本导入即可使用，无需额外安装依赖。
